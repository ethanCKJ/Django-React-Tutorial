# Basic notes app with Django and React
Originally based on a tutorial by Tech with Tim (https://www.youtube.com/watch?v=c-QsfbznSXI). I changed wth UI and added a feature to edit notes.

### Watch a demo here
https://youtu.be/jS7Ajy4pJ9A

## To run
Running the frontend
1. cd root/frontend  
`npm install`
`npm run dev`   

Running the backend  
2. cd root/backend/backend (folder with manage.py)  
`python manage.py runserver`  
This should run the database with sqlite.

Create an account and enjoy!
